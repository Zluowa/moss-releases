安装说明 · 系统会拦

未签名包打开前先读这一页。

Moss 1.0.2 没有 Windows Authenticode，也没有 Apple 公证。系统拦截是预期行为，不是下载坏了。

只从这个页面和 Zluowa/moss-releases 下载。其他来源的安装包请不要放行。

Windows SmartScreen

  1. 下载 未签名安装程序。
  2. 双击后如果出现「Windows 已保护你的电脑」，点「更多信息」。
  3. 再点「仍要运行」，按安装向导完成安装。
  4. 如果被 Defender 隔离，到「病毒和威胁防护」里恢复这份文件后再装。

只有第一次安装需要这样做。之后的版本由 Moss 在后台下载，你决定何时重启安装。

macOS Gatekeeper

  1. 打开 DMG，把 Moss 拖进「应用程序」。
  2. 如果提示无法验证开发者，打开「系统设置」→「隐私与安全性」，拉到被拦记录，点「仍要打开」。
  3. 再用密码或 Touch ID 确认。

Mac 版目前无法自动更新，每个新版本都要这样手动安装一次。

校验

每个 Release 都有 SHA256SUMS。打开前请先对一下哈希。

Get-FileHash .\Moss-1.0.2-x64.exe -Algorithm SHA256
shasum -a 256 -c SHA256SUMS
