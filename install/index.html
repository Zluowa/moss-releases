安装说明 · 系统会拦

未签名包打开前先读这一页。

0.7.2 内测没有 Apple 公证，也没有 Windows Authenticode。这是预期行为，不是下载坏了。

不要把「仍要打开」当成正式发布流程。正式签名包以后才会走另一条通道。

macOS Gatekeeper

  1. 从 Release 下载 zip，先解压。
  2. 不要双击。按住 Control 再点 Moss，或右键选「打开」。
  3. 对话框会写来自身份不明的开发者。选「打开」。
  4. 如果已经被拦过：打开「系统设置」→「隐私与安全性」，拉到被拦记录，点「仍要打开」。
  5. 再用密码或 Touch ID 确认。

这份 Mac zip 是在 Linux 上交叉打的内测包，没有 AppSnap / Swift helper。模拟器窗格等原生能力可能不可用。

Windows SmartScreen

  1. 下载 未签名安装程序。
  2. 双击后如果出现「Windows 已保护你的电脑」，点「更多信息」。
  3. 再点「仍要运行」。
  4. 如果被 Defender 隔离，到「病毒和威胁防护」里恢复这份文件后再装。

校验

每个 Release 都有 SHA256SUMS。打开前请先对一下哈希。

shasum -a 256 -c SHA256SUMS
Get-FileHash .\Moss-0.7.2-win-x64-unsigned.exe -Algorithm SHA256
