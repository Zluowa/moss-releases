# Security Policy

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do not
open a public issue containing exploit details, credentials, personal data, or
unredacted logs.

Include the affected Moss version, operating system, expected behavior, observed
behavior, and the smallest safe reproduction you can provide.

## Supported versions

Only the latest signed public release is supported. Internal or unsigned test
packages are not public releases.

## Release integrity

Official release assets must pass platform signing, macOS notarization where
applicable, installation testing, and SHA-256 publication before release.
