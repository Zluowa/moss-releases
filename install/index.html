怎么打开未签名包

Moss 1.0.2 没有 Windows Authenticode，也没有 Apple 公证。系统拦截是预期的。Windows 只有第一次安装需要这样做，之后会自动更新。Mac 版不会自动更新，每个新版本都要手动安装。

macOS

  1. 打开 DMG，把 Moss 拖进「应用程序」。
  2. 第一次不要双击。按住 Control 再点 Moss，或右键「打开」。
  3. 若已拦过：系统设置 → 隐私与安全性 → 「仍要打开」。

Windows

  1. SmartScreen 出现时点「更多信息」，再点「仍要运行」。
