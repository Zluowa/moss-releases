本机工作区，把编码代理收进一个桌面端。

Moss 跑在你自己的电脑上。连上已经登录好的编码代理，从一个仓库、一件有边界的任务开始。

这两份安装包没有经过 Apple / Microsoft 签名和公证。打开时系统会拦截。请先看 怎么打开未签名包。

下载 Mac（Apple Silicon，zip） 下载 Windows（x64，安装程序）

Mac 包在 Linux 上交叉打出，没有原生 Swift helper，部分能力可能不可用。Windows 是 build-only 未签名 NSIS。没有 Linux 下载。

0.7.2 这次更新

  • 线程目标会留下来，做完一回合后可以按目标继续，而不是每次重说。
  • 新增 /debug 取证模式：观察、复现、调查、修补、验证。
  • 工作区文件搜索和内容搜索，结果能直接开到右侧文件窗。
  • 堆叠 Pull Request：位置标记、按栈确认、合并后刷新。
  • 消息级分叉，线程可以从一条消息另开。
  • 大库启动和流式渲染更快；自动化连续失败会停，而不是一条开关打死。
  • Mac 上的 iOS Simulator 窗格需要本机编出来的 helper。这份交叉内测包没有它。
